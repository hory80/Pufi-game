# Pufi – joc educativ (RO / DE / EN)

Joc educativ pentru copii de ~6 ani: numere, Soroban, steaguri și harta lumii, șah, Pufi, citit (cu acvariu), RoboPufi (programare, mașini simple, circuite, senzori, culori) și Lumea formelor.

- Pagina jocului: `index.html` (un singur fișier), plus `foto/` (monumente), `imn/` (imnuri), `fotbal/` (fotbaliști).
- Publicat cu GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
- Progresul se salvează local pe fiecare dispozitiv (localStorage).
